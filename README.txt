Golf Body 365（PWA版）

■ iPhoneのホーム画面で使うには
このフォルダ一式を HTTPS のWebサーバーに置き、Safariで index.html のURLを開きます。
Safariの「共有」→「ホーム画面に追加」→「追加」で、アプリ風に起動できます。

■ 無料公開の例
GitHub Pages / Cloudflare Pages / Netlify などの静的サイトホスティングに、このフォルダの中身をそのまま配置できます。

■ データ
トレーニング履歴、前回重量、身体記録などは端末のブラウザ内（localStorage）に保存します。
Safariのサイトデータを削除すると記録も消えるため、将来版ではバックアップ/復元機能を追加するのがおすすめです。

■ ChatGPT相談
現版は記録から相談文を自動生成してクリップボードへコピーします。ChatGPTアプリ/サイトに貼り付けて相談できます。
